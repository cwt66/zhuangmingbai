## 为什么保留这份数据

合成样例是单房间结构，测不出：
- 同一工序在多个分区各做一次（吊顶、门套、地漏）
- 复合行一行含多个工序（「墙面基础处理+批嵌砂光」）
- 材料费与安装费分列（大理石台面 / 台面安装费）
- 按「项」报价导致工程量不可核
- 备注里的否定语境（「含拆除，不含垃圾外运」）

来源是公开装修日记，**无法验证业主是否原样上传**。金额与行项结构可信，
但「这是否为最终结算价」不可确认。用于算法回归，不作为定价依据。
