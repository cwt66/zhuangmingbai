## 1. 规则 + 坐标系基线（本作品）

| 指标 | 值 | 口径 |
|---|---:|---|
| 完整黄金标注单据 | **2** | feitai（131 行）、guijiao124（65 行）；单一标注者 A1 |
| auto 档 TP / FP / FN | 10 / 2 / 2 | 只算确定性漏项（进核减金额的那一档） |
| auto 精确率 / 召回率 | **0.833 / 0.833** | Wilson 95%CI **0.552–0.953** |
| all 档精确率 / 召回率 | 0.750 / 1.000 | Wilson 95%CI 0.505–0.898 / 0.757–1.000 |
| 消融 L0 → L2（feitai auto 精确率） | 0.267 → 0.800 | 文本证据词把误报从 19 条压到 10 条 |
| 检测下限 | 单行最小可捕获 **±1.01 元** | 不依赖标注；已知小额盲区如实披露 |
| 注入检出 | **242 / 242** | 下限校验，**不是召回率** |
| 判定指纹一致性 | 12 变体逐字节一致 | arm64 ↔ x86_64 存档可比对 |

**边界（必须与数字一起引用）**：n=2、单一标注者，只作存在性证明，不能外推总体召回率。
`not_applicable` 冲突 1 条单列，不计 FP。
