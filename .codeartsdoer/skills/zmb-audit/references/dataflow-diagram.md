# 数据流（Dataflow Diagram）

> 只画本 Skill 这一条路径。主程序的可选云 provider（MaaS / OCR / RDS / Redis）
> 不在这条链上，画进来会让人误以为「判定依赖云」。

```text
[用户] 报价单 CSV / XLSX / PDF 文本层
   │
   ▼
[1] 上传守门 src/doc_gate.py
   │  只看表头与原文，解析「之前」就判 报价单 / 合同 / 无关
   ├── 不是报价单 ──> 退出码 2 + 证据（不进引擎）
   ▼
[2] 感知层 file provider
   │  编码 UTF-8 / GBK / UTF-16；逗号 / TAB；表头别名；多 sheet 选最满的一张
   ▼
[3] 坐标系 WUA  data/ontology_v0.json（119 概念 / 388 别名）
   │  父类吸收（水电一行不列子项，不判漏）
   │  变体残差排除（同概念不同变体，不算重复）
   ▼
[4] 判定引擎 src/pipeline.py  ← 13 条规则 data/rules_v0.json
   │  漏项集合差 / 重复结构推理 / 算术 / 对账 / 口径 / 义务
   │  零第三方依赖；判定不经过大模型
   ▼
[5] 三档处置 auto / review / manual
   │  只有 auto 档进核减金额；低置信只进待确认清单
   ▼
[6] 证据链 + 判定指纹（16 位）
   │  每条结论 = 原表行号 + 对照基准 + 计算公式 + 证据强度
   ▼
[7] 报告交付门 src/report_gate.py（D1–D7）
   ├── pass / needs_fix ──> stdout 报告
   └── block ──> 「此报告不应交付给业主」，不给结论
   ▼
[8] 审计包 / 回放页（可选，离线复算）
```

## 信任边界

| 边界 | 进来的东西 | 出去之前必须做的事 |
|---|---|---|
| 输入 → 引擎 | 用户可控的表格文本 | 先守门、再判编码与表头；空表明确报错，不返回「没有项目」 |
| 引擎 → 报告 | 工序名、备注、依据文案 | 统一 HTML 转义（XSS 回归测试锁着） |
| 报告 → 业主 | 金额与结论 | 交付门否决权；无依据金额 / 低置信混进核减 / 指纹不可复现 → block |

## 不在这条链上的东西

- **大模型**：主程序里只做「看」（照片 → 行项）和「说」（结论 → 话），
  本 Skill 的 `file` 路径完全不调用模型。
- **云服务**：RDS / Redis / MaaS / OCR 都是主程序的可选依赖，挂了会降级并在
  `/health` 里如实显示，不改变这里的判定结果。
- **训练**：报告页明确写「数据仅用于本次核对，不用于训练」。
