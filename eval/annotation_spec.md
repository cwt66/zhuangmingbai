# 坑点标注规范 v0（评测集 ground truth）

> 适用：装明白·家装报价审计基准集（80–100 份真实单据 + 1000+ 标注）
> 原则：**双人盲标、一致率 ≥80% 才入库、分歧交第三人仲裁；不确定就标「待定」，禁止猜测**
> 每条标注必须能落到「单据行号 + 工序概念 ID 或模板条款」——不能只写"我觉得漏了"

---

## 一、五类坑点定义

| 代码 | 类型 | 定义 | 真实例子（来自公开资料/晒单） |
|---|---|---|---|
| **L** | 漏项 | 场景必做工序未出现在报价单中（对照工序模板的集合差） | 老房翻新不写铲墙皮、垃圾外运、门窗保护；淋浴区防水只做 30cm 不写加高到 1.8m；不写闭水试验 |
| **D** | 重复计价 | 同一工序在多个计费口出现，或异名同项 | 贴地砖已含填缝又单列填缝；陶粒回填含找平又单列找平；新砌墙含找平又单列找平；批荡铲除含腻子铲除又单列 |
| **U** | 口径混用 | 单位/名称/表述不统一，导致不可直接比较 | 踢脚线按"根"报（1 根 2.4m）而别家按"米"；门套按"单边"报实际按周长；"按项"报面积类工序 |
| **V** | 虚高 | 单价显著高于同批/市场（**只标注，初赛不检测**） | — |
| **M** | 模糊表述 | 给后期增项留空间的写法（记录进话术库，不计入核减） | "按实结算""多退少补""暂定""据实""另计""不含五金" |

**边界规则**：
- 同一处问题只标一条，按最严重类型归类（L > D > U > M）
- 双侧部位、多份标本、不同专业步骤造成的"看起来重复"**不算 D**（需人工判断合理性）
- 报价单写"按实结算"但给了封顶价 → 不算 M

## 二、单条标注字段

```
单据ID | 行号 | 坑点类型(L/D/U/V/M) | 归一后工序概念ID | 严重度(高/中/低) |
依据(模板条款/本体概念/工艺惯例) | 标注人 | 仲裁状态(待仲裁/已确认) | 备注
```

示例：
```
SMZ-012 | 17,45 | D | mason.grout | 高 | 贴地砖工艺含填缝，另列重复 | 张三 | 已确认 | 金额1,248
SMZ-012 | -   | L | paint.mesh  | 高 | 老房模板必做：墙面挂网 | 李四 | 已确认 | 参照价2,010
```

---

## 三、标注流程

1. **入库前质检**（5 分钟/份）：行项 ≥20 行、有单位与单价、无软文嫌疑、已脱敏
2. **双人盲标**：两人独立标同一份，互不看对方结果
3. **一致性计算**：按「坑点类型 + 概念ID + 行号」三元组比对；一致率 = 交集 / 并集
   - ≥80% → 入库
   - <80% → 第三人仲裁，并把分歧写进「定义修订记录」
4. **仲裁**：第三人独立判断，必要时回看原单据；仲裁结论即 ground truth
5. **版本化**：每轮修订标注规范（v0 → v1），旧标注按新定义回刷，记录变更

---

## 四、质量标准（写进评测报告）

| 指标 | 目标 |
|---|---|
| 双人一致率（三元组） | ≥80% |
| 每份单据标注时长 | ≥10 分钟 |
| 每份单据平均坑点数 | 8–15 条（低于 5 条疑漏标，高于 25 条疑过度标注） |
| 标注覆盖率（模板必做项） | 100% 逐项过一遍 |

## 五、文件组织

```
eval/dataset/
├── raw/            # 原始单据（脱敏后），命名 SMZ-001.pdf/jpg
├── meta.csv        # 单据元信息：城市/面积/房型/装修方式/来源/是否含决算对比
├── labels/
│   ├── SMZ-001.a.csv   # 标注人A
│   ├── SMZ-001.b.csv   # 标注人B
│   └── SMZ-001.gold.csv# 仲裁后的 gold
└── agreement.csv   # 每份单据的一致率与仲裁记录
```

## 六、合规红线

- 只采集**已公开**的晒单/求助帖，或亲友授权单据；不购买、不爬取登录后内容
- 原始单据只用于内部评测，**不进开源仓库、不进演示视频**
- 演示用「重制样本」：按真实结构改写金额与项目名，去掉一切个人信息
- 标注文件中不出现姓名、电话、地址、公司实名（用"公司A/B/C"）
