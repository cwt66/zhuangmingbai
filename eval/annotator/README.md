# 第二标注者工具包（30 分钟，不需要装任何软件）

> 目的：让**另一个人独立判断**同一批模板项，用来计算两个人的一致性（Cohen's κ）。
> 这件事只有一个价值：证明「不是我们自己说了算」。所以**独立**比「标得漂亮」重要得多。

---

## 一、你要做什么

打开下面两个网页文件（双击即可，不需要联网、不需要装 Python）：

| 文件 | 单据 | 项数 | 预计时间 |
|---|---|---:|---:|
| `annotate_feitai.html` | 上海翡翠台 · 老房全案（131 行） | 39 | 20–25 分钟 |
| `annotate_guijiao124.html` | 124㎡ · 基础报价单（68 行） | 28 | 12–18 分钟 |

每个网页左边是**模板要求做到的工序清单**，右边是**这份报价单的全部行项**。

你要做的是：**逐项判断这份单据里有没有这一项**，点「有 / 没有 / 本单不适用」。

页面会自动把当前项的**标准名 + 所有常见叫法**在单据里标黄，省去你一行行找。
键盘也能用：`1` 有、`2` 没有、`3` 不适用，`←/→` 上下项。

---

## 二、三个选项怎么区分（这是唯一需要理解的地方）

| 选项 | 什么时候选 | 例子 |
|---|---|---|
| **有** | 单据里确实有这一项，**写成别的叫法也算** | 模板要「地面保护」，单据写「地砖成品保护 / 专用地坪保护」→ **有** |
| **没有** | 单据里确实找不到，别名也搜过了 | 模板要「闭水试验」，全文搜 闭水/蓄水/试水 都没有 → **没有** |
| **本单不适用** | 这份报价**范围根本不包含**这一类 | 单据写「基础报价，主材另计」，那么门、洁具、灯具、踢脚线 → **本单不适用** |

判断顺序建议：

```
先看标黄行 → 有，选「有」
没有标黄 → 自己再搜 2–3 个近义词（比如 防水/涂膜/卷材）
还是没有 → 问自己：这份单子本来会不会包含它？
           会 → 「没有」      不会 → 「本单不适用」
```

**拿不准就按「没有」**，并在备注里写一句「不确定，疑似…」。
我们把「拿不准」当信息，不当错误——它正好说明模板或定义需要改。

## 三、三条硬规矩（请务必遵守）

1. **不要打开仓库里的 `eval/golden_labels_*.csv`**，也不要问做过这份标注的人。
   你一旦看到别人的答案，这次一致性就作废了——不是你的问题，是方法失效。
2. **不要修改单据内容**。判断的是「这份单子写了什么」，不是「它应该写什么」。
3. **不要为了「看起来一致」而改判**。分歧比一致更有用：分歧项会被拿去第三人仲裁，
   然后写进标注规范修订记录。

---

## 四、导出与回传

1. 在网页右上角填上你的名字或代号（例：`张三` / `A2`）。
2. 全部判完后点右下角 **「导出标注 CSV」**。
   没判完会拦住你，并跳到第一个没判的项——这是有意的。
3. 你会得到两个文件：

```
feitai.张三.labels.csv
guijiao124.张三.labels.csv
```

4. 把这两个文件放回 `eval/annotator/回传/` 目录（或直接发回给队长）。

> 文件名规则很重要：`单据名.标注人.labels.csv`。
> 同一份单据**只保留一个最终版**；多版本会让脚本直接报错（防止拿错版本对比）。

---

## 五、我们拿它算什么

```bash
python3 eval/cohen_kappa.py --dir eval/annotator/回传
```

会输出每份单据的**观察一致率**和**Cohen's κ**，以及所有分歧项。

入库门槛（写在 `eval/annotation_spec.md` 里，事先定好的）：

| 指标 | 门槛 |
|---|---|
| 观察一致率 | ≥ 0.80 |
| Cohen's κ | ≥ 0.60 |

**达不到就如实写达不到**，并列出分歧项。这比编一个 0.9 有用——
评委问「你怎么知道标注是对的」，能拿出「两个人独立标，κ=0.7x，分歧项在这」，
比说「我们自己标得很仔细」强一百倍。

## 六、常见疑问

**Q：有的项单据里写了，但我怀疑它其实没做，怎么办？**
A：这套标注只判断**「单据上写没写」**，不判断施工质量。写「有」。

**Q：同一项出现两次，算有吗？**
A：算有。重复计价是另一条规则的事，不在这里判。

**Q：某项在备注里被提到（比如「不含五金」），算有吗？**
A：如果备注是明确排除（「不含」「另计」），那这项**没有包含在报价里** → 选「没有」，并在备注写原话。

**Q：我判到一半没时间了？**
A：页面状态在你导出前只存在浏览器里，关掉就没了。建议一次做完一份；
或者先用纸记下进度，回来继续。
