## 3. Q&A 预案（五问）

1. **和 RenoPit 什么区别？** → 它做"问 AI"，我们做"可计算审计"：每条结论=行号+基准+公式+置信度，可点开溯源；对照实验（30 份×3 系统）在初赛前跑完。
2. **置信度怎么来？** → 规则强度×解析质量×对齐确定性×模板匹配度加权合成，再用标注集做 out-of-fold 校准；ECE 报 95% CI。
3. **价格基准哪来？** → 不用外部价格库：漏项金额用同一批报价的横向参照（中位数），只回答"缺了什么、补上大概多少钱"，不判断贵不贵。
4. **数据多少份？** → 校赛 30 份、初赛 80–100 份 + 1000 条标注；标注规范与评测脚本开源，双人盲标一致率 ≥80%。
5. **技术含量在哪？** → 本体库（97→200 概念）+ 规则 DSL + 校准审计（ECE/risk-coverage）+ 级联路由，不是 prompt 包装。
