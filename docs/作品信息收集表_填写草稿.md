## 二、参赛作品简介

**赛题**：赛题1：基于华为云产品打造AI创新应用（中国区）

**作品名称**：装明白——装修报价可计算审计

**应用领域**：生活应用（家装消费 / 消费者权益保护）

**应用技术**：华为云码道 CodeArts 代码智能体（需求理解→代码生成→项目构建→问题修复→部署上线）；ModelArts Studio（MaaS）Qwen-VL 系列做单据结构化、文本模型做报告与话术；RDS PostgreSQL 存项目/行项/工序轴/审计记录；Redis 做解析任务队列与缓存；OBS 存原始单据与报告；ECS + Nginx + HTTPS 完成公网部署。

### 作品介绍 1：方案的背景和价值（≤500 字）

家装是消费投诉重灾区。中国消费者协会《2025年全国消协组织受理投诉情况分析》显示，房屋装修及物业服务类投诉达2.18万件，"低价引流、增项收费和履约难题"被列为年度八大投诉热点之一；上海市消保委口径显示，家装投诉中"预算不透明、恶意增项"占38.5%，平均每户被动增项2.3万元，相当于合同价的15%–25%。

问题不是"看不懂"，而是缺少坐标系：同一道工序有五种叫法、三种计价单位，业主无法把多家报价放到同一张表上比较。装明白面向签合同前的业主——上传2–4家报价单（照片/PDF/Excel），输出可核对、可溯源、带置信度的审计报告：谁漏了项、谁重复收钱、谁口径混乱、补漏后真实成本是多少、拿着什么话去谈。系统把约200个模糊工序名归一为统一工序轴，判断交给可解释规则（漏项集合差、重复计价结构推理、单位换算），每条结论附原表行号、对照基准与计算公式；低置信度结论不进入核减金额，只进待确认清单。我们不判断贵不贵，只判断漏没漏、重没重。

本项目以华为云码道 CodeArts 作为唯一开发底座，把"想法到应用"拆成五个可度量的环节，并逐环节留存过程资产：

## 三、技术方案介绍

### 整体技术方案

五层架构：**感知层**（MaaS Qwen-VL 把照片/PDF 解析为行项 JSON，附字段级置信度）→ **坐标系层**（工序本体约 200 个概念，同义词/上下位/单位换算，将多家报价对齐到同一工序轴）→ **判断层**（审计规则 DSL，12 条规则，不经过大模型：漏项集合差、重复计价结构推理、口径与算术校验）→ **可信层**（置信度合成 + 校准 + 可靠性图 + risk-coverage + 三档处置）→ **表达层**（文本模型生成报告与谈判话术，输出 PDF）。

架构原则：**大模型只做"理解"与"表达"，判断全部交给可解释的规则与计算**——幻觉问题从架构上消除。模型层走 ModelGateway 抽象（配置切换 + 多模型 fallback，型号不写死）。

【配图：五层架构图 / 三家报价单对比表截图 / 证据链展开截图】

### 关键技术模块

**模块1 工序轴对齐（WUA）**：把"墙固/界面剂/基层处理"、"按项/按平米/按米"归一为同一坐标。当前本体 101 概念、221 别名、7 大类，精确/别名/模糊三级对齐。指标：行项对齐准确率（目标 ≥90%）、同义判等 F1（目标 ≥0.85）。

**模块2 审计规则 DSL**：12 条规则覆盖漏项（模板集合差）、重复计价（同概念多行 + 已知工艺包含对）、口径混用（按实结算/单边/按根）、算术校验（合价≠数量×单价）、防水高度不足、拆分报价。规则只依赖本体与模板，不依赖价格库。指标：规则覆盖率、单规则误报率、新增规则成本（人时）。

**模块3 校准审计（Calibrated Audit）**：每条结论输出置信度 c（规则强度 0.4 + 解析质量 0.2 + 对齐确定性 0.2 + 模板匹配度 0.2），在标注集上做 out-of-fold 校准（Platt/Isotonic），输出可靠性图、ECE（含 95% bootstrap CI）与 risk-coverage 曲线；三档处置：≥0.9 自动通过、0.6–0.9 建议复核、<0.6 转人工。**低置信度结论不进入核减金额**。

### 方案最终达到的效果（可量化指标）

**引擎自测（三家合成样例，80㎡ 老房翻新；非真实业主单据，仅用于链路验证）**：

| 公司 | 报价总价 | 漏项补项 | 重复剔除 | 真实成本 | 风险敞口 |
|---|---:|---:|---:|---:|---|
| A 规范型 | 86,498 | 400（1 项） | 0 | 86,898 | — |
| B 低价引流型 | 59,902 | 22,164（17 项） | 0 | 82,066 | 6,100–7,300 |
| C 高价项全型 | 100,146 | 0 | 3,168（2 项） | 96,978 | — |

演示结论：B 表面最低，补漏后 82,066，加上水电按实结算敞口 6,100–7,300 → 88,166–89,366，反超 A 的 86,898。单份审计耗时 <1 秒（纯规则计算）。

**目标指标（W3 用 80–100 份真实单据的实测值替换）**：对齐准确率 ≥90%、漏项召回 ≥80%、重复计价精确率 ≥75%、ECE ≤0.05、覆盖率 80% 时错误率 ≤5%、单次审计成本较"全量强模型"下降 90%。
