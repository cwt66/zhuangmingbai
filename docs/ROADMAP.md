## P0：让真实用户能走完第一步（0–1 个月）

| 事项 | 为什么 | 验收 |
|---|---|---|
| MaaS / OCR 额度 | 真实照片 → 审计的唯一缺口 | 18 张照片跑通，字段准确率 ≥85% |
| 拍照引导页 | 斜拍/阴影会让 OCR 产出伪表格 | 失败时明确要求重拍，而不是给烂结果 |
| PDF 导出 | 业主真正要「能发出去的文件」 | 报告一键导出 PDF，中文不缺字 |
| 3 个真实家庭试点 | 应用价值 30% 的硬证据 | 记录：提示项 / 实际问询 / 核减金额 |

## P1：把「一次审计」变成「一个项目」（1–3 个月）

- **项目空间**：一个业主可保存多轮报价（签约前/签约后/增项），纵向对比。
- **微信小程序 / H5**：拍照上传、报告分享、问询单转发；不做原生 App。
- **试点合作协议模板**：知情同意、数据删除、案例授权三件套。
- **装企侧「透明报价」入口**：装企可自检报价单，减少签约后争议（B 端付费）。
- **完整标注集**：30 份 × 39/28 项，双人盲标 + 第三人仲裁，Cohen's κ ≥ 0.8。

---

## P2：把「装修」变成「可迁移的坐标系」（3–6 个月）

- **汽修维保**：已有迁移 demo；补 20 份真实维保单与工时库，验证第二个行业。
- **工程结算 / 保险理赔**：先做规则与本体可行性评估，不承诺上线。
- **规则市场**：第三方可提交规则包（JSON），经审核后进入规则库；规则版本可追溯。
- **参照价库**：从 4 份家装单据扩到 200+，按城市/面积/工艺分层；无样本仍留空，不编数。

---

## P3：商业化与生态（6–12 个月）

| 模式 | 谁付费 | 前提 |
|---|---|---|
| 业主单次审计（9.9–29.9 元） | 业主 | 报告能直接拿去谈，且有真实核减案例 |
| 社区/物业批量 | 物业/业委会 | 批量入口 + 隐私合规 |
| 保险公司 / 消协合作 | 机构 | 公益属性 + 可审计方法学 |
| 装企透明报价工具 | 装企 | B 端不要求"自证清白"，只做自检 |

**不做的**：不做装修监理、不做施工验收、不做贷款/金融导流、不卖业主线索。

## 风险与止损

| 风险 | 止损 |
|---|---|
| 照片解析始终不稳 | 退回「PDF/Excel 优先」，明确定位为"装企电子报价单审计" |
| 试点找不到 | 用公开晒单的"预算 vs 决算"做事后验证，并在材料里写明局限 |
| 本体权威性被质疑 | 公开构建方法 + 覆盖度 + 与定额/监理实践对标，不自称标准 |
| 大厂做同类功能 | 差异化在"可复算 + 可迁移"，不在功能数量 |
