# 华为云 AI 开发者空间部署指南（公网 Demo）

> 目的：不买 ECS 也能满足赛题「作品真跑在云上 + 可视化 Demo」的资格要求。
> 依据：华为云 AI 开发者空间内置 **DevBridge 公网隧道**，把沙箱端口映射为 HTTPS 公网域名。
> 官方口径：链接随环境释放失效（默认 **72 小时**），属「演示/验收」通道，不是生产托管。

---

## 一、它能解决我们两个问题

| 问题 | 解决方式 |
|---|---|
| 码道 CodeArts 积分不足 | 开发者空间**内置码道**，体验版单次限时（3–6 小时，以控制台为准），可多次进入 |
| 公网 Demo 无处部署（ECS 未充值） | 沙箱跑 FastAPI → DevBridge 映射 8080 → `https://xxx-8080.devbridge-s2.hwtunnel.com` |

**一句话**：沙箱 = 免费的云主机 + 码道 + 公网隧道，足够录制演示视频和应付材料检查。

---

## 二、部署步骤（约 5 分钟）

1. **登录**：`developer.huaweicloud.com`（华为云账号，已完成个人实名）→ 顶部「AI 开发者空间」→ 体验中心
2. **新建会话 / 打开终端**，克隆仓库（公网仓库已就绪，无需上传文件）：
   ```bash
   git clone https://gitee.com/Cwt66/zhuangmingbai.git
   cd zhuangmingbai
   ```
3. **一键启动**：
   ```bash
   bash scripts/devspace_run.sh
   ```
   脚本做三件事：装依赖 → 跑 26 个单测自检 → `uvicorn main:app --host 0.0.0.0 --port 8080`
4. **开隧道**：在沙箱界面找到 DevBridge（开发者隧道）→ 映射 `8080` 端口 → 拿到
   `https://<随机串>-8080.devbridge-s2.hwtunnel.com`
5. **验证**：`curl -sI https://<域名>/` 返回 200/307 即通；浏览器打开 → 首次有安全警告页 → 点「继续访问」
6. **存档**：手机录屏 / 截图（含地址栏完整域名 + 报告页面），存进材料目录

---

## 三、必须知道的坑（官方文档与实际踩坑）

| 坑 | 表现 | 处理 |
|---|---|---|
| 绑地址错 | `127.0.0.1` 时隧道"通但 502" | 必须 `--host 0.0.0.0`（脚本已内置） |
| 首次访问警告 | 浏览器提示证书/安全风险 | 点「继续访问」并允许 Cookie，提前跟看的人说一句 |
| 会话回收 | 域名立即失效 | 演示前重新进环境 → 重新起服务 → 重新映射（2 分钟） |
| 时长限制 | 单次 3–6 小时 | 长任务分段；**关闭前把代码 push 回 Gitee**（沙箱是临时的） |
| 端口占用 | 8080 被占 | `bash scripts/devspace_run.sh 9000` |

---

## 四、材料里怎么写（诚实且有利）

> **可视化 Demo（双通道）**
> ① **实时交互**：部署于华为云 AI 开发者空间沙箱，经 DevBridge 隧道公网访问
> （`https://<域名>`，随环境释放失效，可按第二节步骤 2 分钟重建）；
> ② **长期可访问**：审计报告与作品介绍页托管于华为云 OBS 静态网站（链接固定）；
> ③ 演示视频完整录屏（含公网地址栏）。

**不要**把临时链接当成"永久 Demo 地址"写进材料——评委点开时可能已失效，反而扣分。
正确写法是"实时通道 + 长期静态 + 视频存证"三件套。

## 五、与 ECS 方案的关系

| 方案 | 成本 | 公网 | 有效期 | 定位 |
|---|---|---|---|---|
| AI 开发者空间 + DevBridge | 免费 | ✅ HTTPS | 72h（可重建） | **主力：演示 + 视频** |
| ECS + Nginx | 几十元/月 | ✅ 固定 IP | 长期 | 备选：初赛函评期间长期在线 |
| OBS 静态网站托管 | 近乎免费 | ✅ | 长期 | **补充：报告/介绍页长期可看** |

建议顺序：先用开发者空间把视频录完（零成本，立刻可做）；OBS 静态托管同步做（长期展示）；
ECS 只在"初赛函评期间需要评委随时点开"时再补（几十块钱，届时再决定）。
