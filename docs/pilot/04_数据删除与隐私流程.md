# 数据删除与隐私流程

> 对应 `SECURITY.md` 的承诺。任何一步做不到，就不要在材料里声称「可删除」。

## 1. 收到单据时（T+0）

1. 先脱敏再入库：姓名、电话、地址、小区名、合同编号、二维码全部遮盖；
2. 给案例编号（P01…），**编号与业主身份的对应表只存本地、不进仓库**；
3. 记录同意范围（数据用于评测 / 案例公开 / 完全不公开），写在案例表头部。

## 2. 退出或到期（T+7 天内）

触发条件：业主撤回同意、试点结束、公开前复核不通过。

```bash
# 1) 从案例目录移除原始单据与报告
rm -rf pilot/cases/P01/

# 2) 若已落 RDS/OBS：按案例编号删除记录与对象
#    删除接口需在部署环境实现；没有接口时不要声称已支持云端删除
#    （当前状态：接口待实现，本地文件删除可用）

# 3) 审计摘要含判定指纹但不应含个人信息；确认无残留后回执业主
```

**回执模板**：

```
你的数据已于 ____ 删除，包括：报价单、报告、访谈记录、云端摘要（如适用）。
保留的只有不含个人信息的统计口径：房型/面积段/提示项类别。
如需进一步说明，请联系 项目仓库 Issue 或指导老师。
```

## 3. 公开发布前检查清单

- [ ] 案例表四件套齐全：提示项 / 实际问询 / 核减金额依据 / 系统漏报
- [ ] 核减金额有版本对比依据；无依据的写「未量化」，不估算
- [ ] 姓名、电话、地址、小区名、合同编号、原单据影像全部不出现
- [ ] 业主勾选了「同意匿名公开」，且没有勾选「完全不公开」
- [ ] 系统漏报（如有）一并呈现，不只展示成功案例
- [ ] 案例表述为「个案」，不外推总体效果

## 4. 已知限制（如实写进材料）

- 云端删除接口尚未实现；当前只能在本地文件层完成删除。
- 试点只有 3 户，不能据此声称「平均节省 X 元」或「准确率 X%」。
- 匿名案例公开前需业主二次确认，不能拿知情同意书里的笼统授权代替。
