# 真实试点工具包（3 户）

> 用途：签约前介入，记录「提示项 → 实际问询 → 核减金额」，为社会效益提供一手证据。
> 现状：**工具就绪，试点未开展**。不要把这些模板写成已完成的案例。

| 文件 | 什么时候用 |
|---|---|
| [01_知情同意书.md](./01_知情同意书.md) | 联系业主时，说明数据用途、留存、删除权 |
| [02_访谈提纲.md](./02_访谈提纲.md) | 30 分钟访谈，采单据与决策过程 |
| [03_案例记录表.md](./03_案例记录表.md) | 每户一份，记录提示项、问询、结果与核减金额 |
| [04_数据删除与隐私流程.md](./04_数据删除与隐私流程.md) | 退出、到期、公开发布前的处理动作 |

## 执行顺序

1. 先发知情同意书，取得书面/文字确认，再收单据；
2. 单据**当场脱敏**（姓名、电话、地址、小区名、合同编号全部遮盖）后再进引擎；
3. 访谈按提纲走，不诱导业主评价「值不值」，只问「你据此做了什么」；
4. 每份报告导出 PDF + 审计包，双方各留一份；
5. 签约后 2 周初访、30 天终访，回填实际问询与核减金额（初赛只需初访）；
6. 公开发布案例前走 04 的检查清单，任何一项不通过就不发布。

## 口径纪律

- 不作法律、财务、工程意见；报告只核对漏没漏、重没重、口径与算术。
- 核减金额以**业主实际谈下来的金额**为准，不以系统估算为准。
- 样本只有 3 户，结论按「案例证据」表述，不外推总体。
