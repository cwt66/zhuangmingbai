# 知情同意书（真实用户试点）

**项目名称**：装明白 · 可计算审计（第十一届华为 ICT 大赛中国创新赛参赛作品）
**团队**：武汉理工大学 · 奇点降临
**联系**：项目仓库 Issue 或指导老师

---

## 我们想做什么

邀请你在**签装修合同之前**使用一次装明白：上传 2–4 家报价单（PDF / Excel / CSV / 照片），
系统给出一份可核对的审计报告，指出漏项、重复计价、口径与算术问题。
我们想记录的是：系统提示了什么、你是否据此向装修方提问、最终谈下来省了多少。

## 你需要知道的四件事

1. **自愿参加**，不参加或中途退出都不影响任何服务； refusing 无需理由。
2. **不作决策依据**：报告不构成法律、财务或工程意见，也不判断「贵不贵」；最终决定由你做。
3. **数据用途**：仅用于算法回归评测与匿名案例展示；不用于商业推销，不转交第三方。
4. **删除权**：随时可以要求删除你提供的单据与报告，我们会在 7 天内完成并回执。

## 我们会收集什么

| 数据 | 是否必须 | 处理方式 |
|---|---|---|
| 报价单 / 合同（脱敏后） | 必须 | 遮盖姓名、电话、地址、小区名、合同编号后入库 |
| 房屋面积、房型、装修范围 | 必须 | 只保留「80㎡ / 老房翻新 / 半包」这类粒度 |
| 访谈记录 | 必须 | 匿名化，标注人代号代替姓名 |
| 签约后实际核减金额 | 可选 | 没有就说没有，不追问、不估算 |

## 公开与署名

案例公开时只出现：「房型 + 面积段 + 提示项 + 实际问询 + 核减金额」。
不出现姓名、联系方式、小区名、原单据影像。若你希望完全不公开，勾选下面第 4 项。
